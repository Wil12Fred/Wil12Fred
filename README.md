## Hi, I'm Wilber 👋

Software engineer. Below are my public projects, grouped by area. Every
repository has a README with build and run steps, and CI where it builds
headless.

### Developer tools
- **[agent-plugins](https://github.com/Wil12Fred/agent-plugins)**: Claude Code plugin marketplace with an agent CLI that is also an MCP server, cross-agent skills, subagents, and a Slack bridge for driving coding-agent sessions from a phone. Python.

### Computer graphics & vision
- **[software-rasterizer-fltk](https://github.com/Wil12Fred/software-rasterizer-fltk)**: a software rasterizer from first principles: line drawing, fill, clipping, perspective, depth buffer, lighting. C++.
- **[image-processing-from-scratch](https://github.com/Wil12Fred/image-processing-from-scratch)**: FFT, Wiener deconvolution, spatial filters and morphology on raw pixels, with a Qt viewer. C++.
- **[delaunay-dijkstra-astar](https://github.com/Wil12Fred/delaunay-dijkstra-astar)**: Delaunay triangulation as a road map, Dijkstra drawn in OpenGL, and A* on a grid. C++.
- **[leap-motion-whac-a-mole](https://github.com/Wil12Fred/leap-motion-whac-a-mole)**: 3D Whac-a-Mole played with bare hands through a Leap Motion, multiplayer over TCP. C++, OpenGL.

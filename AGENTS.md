# AGENTS — the Wil12Fred profile repository

This repository is the GitHub profile page (`README.md`) and the place where the
rules for every public repository of the account live.

**Adding, importing, renaming or publishing a repository?** Follow the
`repo-acceptance` skill: [`.claude/skills/repo-acceptance/SKILL.md`](.claude/skills/repo-acceptance/SKILL.md).
It covers the gates (secrets, personal data, organization names, redistributability,
license), the shared standard, verification on GitHub Actions, naming, topics, and
indexing the repository in `README.md`.

Quick check of a clone:

```bash
python3 .claude/skills/repo-acceptance/scripts/check_repo.py ~/Projects/Personal/src/<repo> --github
```

`README.md` is the public profile: keep it to the project index — no tooling notes.
